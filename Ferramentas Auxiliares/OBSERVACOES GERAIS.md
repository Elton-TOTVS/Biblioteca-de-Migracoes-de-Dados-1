# Ferramentas desenvolvidas para Auxilio nas Migrações e Desenvolvimento de Scripts

- data_analisys: App PY para Mapeamento de Bancos de Dados e Relacionamentos entre Tabelas
- Conversor de arquivos BT para banco: App Py para migração de arquivos .bt para Banco de Dados
- conversor_bt_sql_gui: App Py com interface gráfica para migração de arquivos .bt para SQL Server melhoria do "Conversor de arquivos BT para banco"
