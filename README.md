# Biblioteca-de-Migracoes-de-Dados
Repositório destinado a inclusão de templates e scripts para N tipos de Migração entre sistemas e produtos.

## Sumário

# 1 Docs - MIT'S e Documentos Importantes
- Documentações importantes para envio obrigatório a cada ciclo de Migração

# 2 Ferramentas Auxiliares
- Aplicativos e Ferramentas desenvolvidas ou compartilhadas para Auxilio no processo de Migração e Desenvolvimento de Scripts

# 3 Migração de Dados
- Núcleo de operação principal, contém todos os Scripts de Migração e suas observações que devem ser verificadas antes de cada uso para fins de ajuste e adaptação entre projetos

# 4 Scripts Auxliares pra Quaisquer Projetos
- Scrips desenvolvidos de forma independente para Auxilio em quaisquer projetos, seja para obtenção de informações, quanto para efetuar validações fora dos escopos principais mas ainda sim relevantes par o sucesso das migrações
